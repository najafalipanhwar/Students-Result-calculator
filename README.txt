# Student Result Calculator

A simple school-style result calculator built with HTML, CSS and JavaScript.

## Features

- Student name and roll number
- Multiple subjects
- Add/remove subjects
- Total marks
- Obtained marks
- Percentage
- Grade
- Pass/Fail status
- Subject-wise result table
- Print result
- Responsive mobile design

## How to Run

1. Open this folder in VS Code.
2. Open `index.html` in a browser.
3. Enter student information.
4. Enter subject marks.
5. Click **Calculate Result**.

## Grade Scale

90%+ = A+
80–89.99% = A
70–79.99% = B
60–69.99% = C
50–59.99% = D
40–49.99% = E
Below 40% = F

Passing percentage in this demo is 40%.
